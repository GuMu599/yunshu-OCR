# 四篇论文公式覆盖审计（2026-08-11）

## 结论

这次测试中真正的“公式识别不到”并不是一种情况，而是四条不同链路：

1. 多行公式组在拆分前被整块长度门槛拒绝；
2. 同一公式组被版面模型输出为一个外框和多个碎片框，后续处理相互覆盖；
3. pix2tex 对同一小公式在 300 DPI 与 200 DPI 下表现不同；
4. 行内等式从未进入独立公式检测路径，因此只能作为普通正文保留。

后续复核还发现第五条独立链路：同一公式区域可能同时被公式检测器和无框表候选覆盖。前者输出 LaTeX，后者在表格识别被拒绝后回退为原生正文，导致公式以“原始文字 + LaTeX”出现两遍。

修复后，四篇回归结果分别为：SURADF 论文 12 个显示公式和 6 个行内公式，石墨烯论文 1 个显示公式和 3 个行内公式，物理教育论文 3 个显示公式和 7 个行内公式，网球支架论文保持 0 个显示公式和 0 个行内公式。四篇均为离线转换，公式图片降级计数均为 0。

## 逐篇分类

### 亚洲货币合作和人民币区域化进程（SURADF）

- 第 3 页公式 (1)：单行显示公式。检测一直存在，但视觉识别容易混淆下标、横线和求和上下限。现在对可靠原生文字层优先进行保守 LaTeX 恢复。
- 第 3 页公式 (2)：三个结构相同的堆叠方程。版面模型给出一个外框，内部又有碎片框；原流程可能整组消失或只留下部分行。现在合并碎片框、按三条公式拆分，并逐行输出。
- 第 3 页公式 (3)：三个带傅里叶项的堆叠方程。原生文本长度为 358，超过旧的 300 字符门槛，因此在拆分前整组被当作正文拒绝。现在先判断并拆分公式组，再对单行应用门槛。
- 第 4 页：三条假设、Q(m) 公式和残差平方模型，共五个显示公式，继续走视觉识别路径。
- 正文中的短等式：`i = 1`、`β_i = 0`、`β_j = ρ_j - 1`、`t = 1`、`β_m = 0`、`t = m + 1`，现在以行内 LaTeX 保留。

### 氧化石墨烯的可控还原及结构表征

- 第 4 页一个独立显示公式，版面模型能够检测并输出。
- `λ = 0.154 nm`、`2d sinθ = nλ`、`d = 0.892 nm` 属于正文内短等式，旧流程不会产生公式元素。现在转换为行内 LaTeX，并保留单位。

### 原始问题教学：物理教育改革的新视域

- 第 6 页三条并列显示公式。拆分后的裁剪在 300 DPI 下 pix2tex 输出为空或结构损坏，但同一裁剪在 200 DPI 下可识别。
- 修复后，首次识别结构不成立时自动以 200 DPI 重试；三条均保留为公式，不再降级成图片。
- 正文中的 `R = 3r`、`R = 2r` 和 `g = 9.8 m·s⁻²` 走行内公式路径；单位点乘与负指数会转换为 LaTeX。

### 网球支架置入治疗成人股骨头缺血性坏死

- 没有独立数学显示公式。
- 日期、分期、百分数和医学编号不能因为包含数字而被误判为公式。
- 回归要求显示公式数为 0、公式图片降级为 0，防止为了提高召回率引入假阳性。

## 第一性原理根因

公式转换链路由“候选发现、区域切分、内容识别、结构校验、Markdown 序列化”五个边界组成。先前的问题分别发生在不同边界：

- 候选发现：版面模型只发现独立显示公式，不负责正文内短等式。
- 区域切分：堆叠公式被当作一张大图送入单公式模型；嵌套框又造成重复或互相覆盖。
- 门槛顺序：整块文本先经过 300 字符门槛，导致本应拆成三条的公式组在拆分前被拒绝。
- 识别输入：公式模型对裁剪分辨率敏感，固定 300 DPI 不是所有小字号公式的最优输入。
- 推理稳定性：pix2tex 的预处理会采样随机变换，相同裁剪可能得到不同结果。
- 结果校验：旧校验只检查是否出现数学命令，未检查括号、花括号、环境和截断结构是否闭合。
- 行内格式：旧流程没有行内等式路径；新增路径早期又可能截断单位或误处理堆叠公式原生文本。

## 已实施修复

- 合并同一公式组的外框和内部碎片框。
- 公式组先拆分、单行后校验，避免整组长度误杀。
- 行裁剪增加纵向留白，保留下标、上标、横线和求和上下限。
- 可靠的原生公式文字层优先恢复 LaTeX；扫描件和不可靠文字层继续走 pix2tex。
- pix2tex 推理固定随机状态并在调用后恢复全局状态，保证相同输入可复现。
- pix2tex 不提供校准后的序列置信度，报告不再伪造 `0.99`，而是明确记录为未知。
- 300 DPI 识别失败时以 200 DPI 重试，成功次数写入 `formula_multiscale_recovered`。
- 拒绝花括号、方括号、LaTeX 环境不闭合以及无数学关系的伪数组输出。
- 增加保守行内等式转换，支持希腊字母下标、常见单位、`m/s²` 与 `m·s⁻²`。
- 堆叠公式原生文本不再被行内正则二次切碎。
- 公式识别成功后，以原始公式检测框为排除区域，按 PDF 字符中心坐标从重叠正文候选中删除已被 LaTeX 表达的字符；公式框外的说明文字和公式编号继续保留。
- 清理时拒绝裁剪框外仅因字形边界相交而被 PyMuPDF 捎入的字符，避免残留半截正文。
- 短公式编号仅在文本完全相同且空间重叠时去重，避免 `(2)`、`(3)` 被宽泛候选重复输出。
- 回归清单增加 `inline_formulas_min`、`formula_fallback_images_max` 与 `formula_text_duplicates_remaining_max`。

## 跨通道重复验证

修复后重新转换四篇论文。SURADF 论文删除了 3 个重叠文本候选，另外三篇删除数为 0；四篇的 `formula_text_duplicates_remaining` 均为 0。对最终 `report.json` 再做文本项与公式项的 bbox 交叉扫描，四篇剩余空间重叠对均为 0。SURADF 仍输出 12 个显示公式和 6 个行内公式，石墨烯论文仍为 1/3，物理教育论文仍为 3/7，医学论文仍为 0/0，未以降低公式召回率换取去重结果。

## 仍然存在的边界

当前修复证明的是公式覆盖和处理稳定性，不等于每个视觉符号都达到人工校对级准确率。pix2tex 仍可能把形近字符混淆，例如 `Z/Y`、`H/Π` 或复杂下标。四篇测试中的 SURADF 第 4 页和物理教育第 6 页仍有这种字符级风险。因此：

- 回归计数用于防止公式再次整组消失；
- 结构校验用于阻止明显残缺的 LaTeX 冒充成功；
- 若要宣称学术级公式准确率，还需要为公式建立逐条金标准 LaTeX，并计算符号或树结构差异，而不能只看公式数量。
